# Lokalizace (i18n)

UI texty pluginu jsou v `src/locales/<kód_jazyka>.json` — plochý JSON, klíč → text, žádný text
natvrdo v `src/main.ts`. Nový jazyk:

1. Zkopíruj `src/locales/en.json` jako `src/locales/<kód>.json` (BCP‑47/ISO 639‑1, např. `de`, `pl`).
2. Přelož hodnoty, klíče a strukturu neměň. Kontext ke každému klíči: `src/locales/_context.md`.
3. `menu.fitTo.pages` je množné číslo — objekt `{ one, few, many, other }` podle
   [CLDR pravidel tvého jazyka](https://www.unicode.org/cldr/charts/latest/supplemental/language_plural_rules.html);
   použij jen kategorie, které jazyk skutečně rozlišuje.
4. Zaregistruj jazyk v `src/i18n.ts` (`LOCALES`), přidej label.
5. `npm run typecheck` a pošli PR.

Běhový mechanismus: `src/i18n.ts` (`t()` pro prostý text, `tn()` pro množné číslo přes
`Intl.PluralRules`). Chybějící klíč se vypíše jako `⟦key⟧` místo tichého pádu na angličtinu —
pokud tohle v menu uvidíš, něco chybí přeložit.
